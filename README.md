## 🚀 # 🎬 Netflix-style AIOps Dashboard

An AI-powered, containerized AIOps dashboard that simulates how Netflix might monitor its streaming 
infrastructure in real-time using machine learning.

## 🚀 Features

- ✅ Real-time stream traffic simulation (users, response time, stream quality, error rate)
- ✅ Intelligent anomaly detection using Isolation Forest
- ✅ Visual anomaly insights via Streamlit dashboard
- ✅ Lightweight and Dockerized
- ✅ Simulates real-world streaming system monitoring
